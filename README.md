تطبيق ديسكتوب هندسي احترافي ومحاكي متقدم لدوائر التحكم الكلاسيكي (Classic Control) مصمم ليكون بديلاً عصرياً شاملاً لبرنامج EKTS القديم، مع واجهة داكنة مريحة للعين، تفاعلية وسلاسة فائقة بمعدل 60+ إطار في الثانية، ودعم كامل للغتين العربية والإنجليزية.

## ⚡ أبرز المزايا والمواصفات (Key Features)

### 1. توصيل وتفريغ الأسلاك بمرونة وسلاسة فائقة (Smart Wire Engine)
* **توصيل هجين (Hybrid Wire Routing):** مسار سلك حر وانسيابي، مع إمكانية الضغط على زر `Shift` للتحويل الفوري إلى زوايا هندسية قائمة 90° (Orthogonal).
* **تفريغ الأسلاك اللحظي (Instant T-Junction Branching):** عند سحب سلك من أي طرف والاقتراب من أي سلك موجود، ينشئ البرنامج نقطة تفريع قياسية ($\bullet$) ويقسم السلك تلقائياً دون أي تعقيد.
* **تحديد جماعي وتحريك ومسح (Marquee Box Selection):** إمكانية رسم صندوق تحديد بالماوس لنقل مجموعة عناصر وأسلاك دفعة واحدة أو حذفها بزر `Delete`.

### 2. محاكاة حية وتأثيرات بصرية وصوتية واقعية (Live Sensory Simulation)
* **أسلاك متوهجة حسب الجهد والطور (Potential-Aware Glowing Lines):**
  * فازة أولى L1: متوهجة بلون أحمر نيون.
  * فازة ثانية L2: متوهجة بلون أصفر/ذهبي نيون.
  * فازة ثالثة L3: متوهجة بلون أزرق نيون.
  * خط التعادل Neutral: متوهج بلون سماوي Cyan.
  * الأرضي PE: متوهج بلون أخضر.
  * الأسلاك غير المشحونة (Dead/Off): تظل بلون رمادي داكن مطفأ.
* **سريان التيار (Current Flow Particles):** نبضات ضوئية متحركة توضح اتجاه سريان التيار الفعلي في المسارات الحاملة للحمل.
* **حركة ميكانيكية حية للكونتاكتورات:** تنجذب نقاط التلامس المفتوحة NO وتغلق بحركة زنبركية، وتفتح النقاط المغلقة NC مع **صوت طقة ميكانيكية واقعية (Contactor Clack)** مولدة برمجياً (Web Audio API).
* **دوران ديناميكي للمحركات (Induction Motor Dynamics):**
  * المحرك يدور بزاوية دوران مستمرة مع مروحة تبريد حركية.
  * يتسارع المحرك بنعومة مع عزم القصور الذاتي (Inertia Ramp) ويتباطأ عند الفصل.
  * كشف فوري لترتيب الفازات (يدور مع عقارب الساعة CW عند توصيل L1-L2-L3، أو يعكس دورانه CCW عند تبديل أي فازتين).
  * عداد سرعة رقمي مدمج يوضح الـ RPM الحقيقي وصوت هدير المحرك المتناغم مع السرعة.
* **المؤقتات الزمنية (Timers):** شاشة رقمية مدمجة على جسم التايمر تعد تنازلياً بالثواني وأجزاء الثانية، مع تبديل وضع النقاط فور انتهاء الزمن.
* **كشف وحماية القصر (Short Circuit Protection):** عند تلامس فازتين أو فازة مع نيوترال بدون حمل، يفصل القاطع فورياً ويطلق وميضاً وصوت إنذار تحذيري لحماية اللوحة.

### 3. بنك دوائر تعليمية تفاعلية جاهزة (Curated Curriculum)
مقسم إلى ثلاثة مستويات تعليمية يمكن تحميل أي منها بضغطة زر:
* **المستوى الأول (سهل):**
  * دائرة التشغيل المباشر (Direct-On-Line DOL) مع Start/Stop واستمرارية وأوفرلود ولمبات بيان.
  * التحكم من مكانين مختلفين (Two-Station Control).
  * التشغيل اللحظي والمستمر (Inching / Jogging).
* **المستوى الثاني (متوسط):**
  * دائرة عكس حركة محرك 3 فاز (Forward/Reverse) بإنترلوك كهربي متقاطع (NC 21-22) وإنترلوك ميكانيكي بالأزرار.
  * دائرة تشغيل محركين بالتتابع (Sequential Control).
  * دائرة مضخة مياه بعوامة مفتاح Hand-Off-Auto.
* **المستوى الثالث (متقدم):**
  * دائرة بدء الحركة ستار-دلتا أوتوماتيك (Automatic Star-Delta Starter) بـ 3 كونتاكتورات وتايمر متخصص ومحرك 6 أطراف.

### 4. أدوات الشرح والعرض للمحاضرين (Teaching Tools)
* **قلم الشرح الفسفوري (Laser Highlighter Pen):** رسم مسارات التيار والدوائر مباشرة على الشاشة أمام الطلاب؛ تتلاشى الخطوط بنعومة وتلقائياً بعد ثوانٍ أو بزر مسح فوري.
* **الأفوميتر الافتراضي (True-RMS Multimeter):** مجسان (أحمر وأسود) لقياس الجهد المتردد AC، الجهد المستمر DC، وفحص التوصيلية والاستمرارية مع صفير Buzzer.
* **شرح مبسط لكل عنصر (Hover Tooltips):** عند الوقوف على أي عنصر يظهر كارت توضيحي باللغة المختارة يوضح وظيفته، رمزه القياسي، وتفسير أرقام أطرافه ($13-14, 21-22, 95-96, A1-A2$).
* **تصدير المخططات:** تصدير كـ PDF مع جدول بيانات هندسي رسمي (Cartouche)، أو كملف مشروع بصيغة `.ccp`.

## 🚀 طريقة التشغيل (Quick Start)

### 1. تشغيل نسخة الويب السريعة (Browser Mode)
```bash
npm install
npm run dev
```
افتح الرابط: `http://localhost:5173`

### 2. تشغيل كتطبيق ديسكتوب أصلي (Desktop App via Electron)
```bash
npm run desktop
```

### 3. تشغيل الاختبارات الآلية (Unit Tests)
```bash
npm test
```

### 4. بناء نسخة الإنتاج (Production Build)
```bash
npm run build
```

## ⌨️ اختصارات لوحة المفاتيح (Keyboard Shortcuts)

| الاختصار | الوظيفة |
| :--- | :--- |
| **Shift (مع السحب)** | توجيه مسار السلك بزوايا 90° قائمة هندسية |
| **الضغط على سلك** | إنشاء نقطة تفريع جديدة فوراً (T-Junction Branch) |
| **Space + السحب بالماوس** | تحريك لوحة الرسم بسلاسة (Infinite Pan) |
| **عجلة الماوس (Scroll)** | تكبير وتصغير اللوحة (Zoom In / Out) |
| **R** | تدوير العنصر المحدد 90 درجة |
| **Delete / Backspace** | حذف العناصر أو الأسلاك المحددة |
| **Esc** | إلغاء التحديد وإغلاق الأدوات العائمة |

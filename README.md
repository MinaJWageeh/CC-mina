تطبيق ديسكتوب هندسي احترافي ومحاكي متقدم لدوائر التحكم الكلاسيكي (Classic Control) مصمم ليكون بديلاً عصرياً شاملاً لبرنامج EKTS القديم، مع واجهة داكنة مريحة للعين، تفاعلية وسلاسة فائقة بمعدل 60+ إطار في الثانية، ودعم كامل للغتين العربية والإنجليزية.

## ⚡ أبرز المزايا والمواصفات (Key Features)

### 1. توصيل وتفريغ الأسلاك بمرونة وسلاسة فائقة (Smart Wire Engine)
* **توصيل هجين (Hybrid Wire Routing):** مسار سلك حر وانسيابي، مع إمكانية الضغط على زر `Shift` للتحويل الفوري إلى زوايا هندسية قائمة 90° (Orthogonal).
* **تفريغ الأسلاك اللحظي (Instant T-Junction Branching):** عند سحب سلك من أي طرف والاقتراب من أي سلك موجود، ينشئ البرنامج نقطة تفريع قياسية ($\bullet$) ويقسم السلك تلقائياً دون أي تعقيد.
* **تحديد جماعي وتحريك ومسح (Marquee Box Selection):** إمكانية رسم صندوق تحديد بالماوس لنقل مجموعة عناصر وأسلاك دفعة واحدة أو حذفها بزر `Delete`.

### 2. محاكاة حية وتأثيرات بصرية وصوتية واقعية (Live Sensory Simulation)
* **أسلاك متوهجة حسب الجهد والطور (Potential-Aware Glowing Lines):**
  * فازة أولى L1: متوهجة بلون أحمر نيون.
  * فازة ثانية L2: متوهجة بلون أصفر/ذهبي نيون.
  * فازة ثالثة L3: متوهجة بلون أزرق نيون.
  * خط التعادل Neutral: متوهج بلون سماوي Cyan.
  * الأرضي PE: متوهج بلون أخضر.
  * الأسلاك غير المشحونة (Dead/Off): تظل بلون رمادي داكن مطفأ.
* **سريان التيار (Current Flow Particles):** نبضات ضوئية متحركة توضح اتجاه سريان التيار الفعلي في المسارات الحاملة للحمل.
* **حركة ميكانيكية حية للكونتاكتورات:** تنجذب نقاط التلامس المفتوحة NO وتغلق بحركة زنبركية، وتفتح النقاط المغلقة NC مع **صوت طقة ميكانيكية واقعية (Contactor Clack)** مولدة برمجياً (Web Audio API).
* **دوران ديناميكي للمحركات (Induction Motor Dynamics):**
  * المحرك يدور بزاوية دوران مستمرة مع مروحة تبريد حركية.
  * يتسارع المحرك بنعومة مع عزم القصور الذاتي (Inertia Ramp) ويتباطأ عند الفصل.
  * كشف فوري لترتيب الفازات (يدور مع عقارب الساعة CW عند توصيل L1-L2-L3، أو يعكس دورانه CCW عند تبديل أي فازتين).
  * عداد سرعة رقمي مدمج يوضح الـ RPM الحقيقي وصوت هدير المحرك المتناغم مع السرعة.
* **المؤقتات الزمنية (Timers):** شاشة رقمية مدمجة على جسم التايمر تعد تنازلياً بالثواني وأجزاء الثانية، مع تبديل وضع النقاط فور انتهاء الزمن.
* **كشف وحماية القصر (Short Circuit Protection):** عند تلامس فازتين أو فازة مع نيوترال بدون حمل، يفصل القاطع فورياً ويطلق وميضاً وصوت إنذار تحذيري لحماية اللوحة.

### 3. بنك دوائر تعليمية تفاعلية جاهزة (Curated Curriculum)
مقسم إلى ثلاثة مستويات تعليمية يمكن تحميل أي منها بضغطة زر:
* **المستوى الأول (سهل):**
  * دائرة التشغيل المباشر (Direct-On-Line DOL) مع Start/Stop واستمرارية وأوفرلود ولمبات بيان.
  * التحكم من مكانين مختلفين (Two-Station Control).
  * التشغيل اللحظي والمستمر (Inching / Jogging).
* **المستوى الثاني (متوسط):**
  * دائرة عكس حركة محرك 3 فاز (Forward/Reverse) بإنترلوك كهربي متقاطع (NC 21-22) وإنترلوك ميكانيكي بالأزرار.
  * دائرة تشغيل محركين بالتتابع (Sequential Control).
  * دائرة مضخة مياه بعوامة مفتاح Hand-Off-Auto.
* **المستوى الثالث (متقدم):**
  * دائرة بدء الحركة ستار-دلتا أوتوماتيك (Automatic Star-Delta Starter) بـ 3 كونتاكتورات وتايمر متخصص ومحرك 6 أطراف.

### 4. أدوات الشرح والعرض للمحاضرين (Teaching Tools)
* **قلم الشرح الفسفوري والـ Laser Highlighter:** رسم مسارات التيار والدوائر التوضيحية مباشرة على الشاشة أمام الطلاب؛ تتلاشى الخطوط بنعومة وتلقائياً بعد ثوانٍ أو تظل ثابتة مع لوحة ألوان نيون وممحاة ذكية.
* **الأفوميتر والـ Clamp Meter الافتراضي (Virtual Multimeter):**
  * قياس الجهد المتردد AC (220V/380V).
  * قياس الجهد المستمر DC (+24V).
  * فحص الاستمرارية والتوصيلية (Continuity) مع صوت طنين Buzzer.
  * **قياس التيار المتردد (AC Ammeter & Clamp):** قياس تيار البدء العالي للمحرك (Inrush Current ~32A) وتيار التشغيل المستقر (~7.5A)، بالإضافة لتيار ملفات الكونتاكتور ولمبات الإشارة.
* **الوضع النهاري والليلي (Light / Dark Themes):** تبديل سلس بضغطة زر بين المظهر الليلي الفاخر المريح للعين والوضع النهاري عالي التباين المناسب للطباعة والعرض على أجهزة البروجكتور.
* **شرح مبسط لكل عنصر (Hover Tooltips):** عند الوقوف على أي عنصر يظهر كارت توضيحي باللغة المختارة يوضح وظيفته، رمزه القياسي، وتفسير أرقام أطرافه ($13-14, 21-22, 95-96, A1-A2$).
* **تصدير المخططات:** تصدير كـ PDF عالي الدقة مع جدول بيانات هندسي رسمي (Cartouche)، أو كصورة، أو كملف مشروع بصيغة `.ccp`.

## ⚡ كيفية التثبيت والتشغيل (Installation & Quick Start)

### 🥇 الطريقة الأولى (الأسهل لمستخدمي Windows - تشغيل بضغطة واحدة):
إذا قمت بتحميل المشروع كملف ZIP أو قمت بعمل `git clone`:
1. تأكد من وجود **[Node.js](https://nodejs.org/)** على جهازك (نسخة LTS مجانية).
2. اضغط مرتين (Double Click) على الملف المباشر:
   ```text
   Classic-Control-Studio.bat
   ```
   *(أو ملف `Run.bat`)*
3. **سيقوم الملف تلقائياً بكل شيء:** فحص المكتبات وتثبيتها وبناء التطبيق وفتحه فوراً في نافذة سطح مكتب ديسكتوب أصلية ومستقلة بدون متصفح!

---

### 💻 الطريقة الثانية (عبر سطر الأوامر لجميع الأنظمة Windows / Mac / Linux):
```bash
# 1. استنساخ المستودع
git clone https://github.com/MinaJWageeh/CC-mina.git
cd CC-mina

# 2. تثبيت المكتبات
npm install

# 3. تشغيل وضع التطوير والمحاكاة السريعة
npm run dev
```
افتح المتصفح على الرابط الموضح: `http://localhost:5173`

## 📖 دليل الاستخدام السريع (How to Use)

1. **إضافة العناصر (Components Palette):**
   - اسحب أو اضغط على أي عنصر من القائمة الجانبية (قواطع CB، كونتاكتورات، بوش بوتن، محركات 3 فاز، تايمرات، لمبات بيان).
2. **توصيل الأسلاك (Smart Wiring):**
   - اضغط مع السحب من أي طرف توصيل (Terminal) إلى طرف آخر.
   - **الزوايا القائمة 90°:** اضغط باستمرار على زر `Shift` أثناء سحب السلك للحصول على مسارات هندسية قائمة.
   - **تفريغ سلك جديد (T-Junction):** اسحب السلك واقترب من أي سلك موجود وافلته؛ سيتم إنشاء نقطة تفريع سوداء ($\bullet$) وتقسيم السلك تلقائياً.
3. **بدء المحاكاة والتشغيل (Simulation Run):**
   - اضغط على زر **تشغيل (Run / Play)** في الشريط العلوي لتفعيل الكهرباء.
   - ستتوهج الأسلاك الحية بألوان الفازات الفورية (L1 أحمر، L2 أصفر، L3 أزرق، N سماوي).
   - اضغط على أزرار **Pushbuttons** بالماوس (تعمل بنظام الزنبرك اللحظي؛ تضغط وتعود لوضعها عند رفع يدك).
   - راقب انغلاق الكونتاكتورات وسماع صوت الطقة الميكانيكية، ودوران مروحة المحرك وتزايد عداد الـ RPM.
4. **استخدام الآفوميتر والـ Clamp Meter:**
   - اضغط على أيقونة الملتيميتر في الشريط العلوي.
   - ضع المجس الأحمر والأسود على أي نقطتين لقياس فرق الجهد (AC/DC) أو فحص التوصيلية.
   - أو اختر وضع **AC Amperes (A~)** ومرر كليبس القياس حول أي سلك حامل للتيار لقراءة شدة التيار اللحظية.
5. **شرح المحاضرات بالليزر والقلم (Laser & Pen):**
   - اضغط على أيقونة القلم الفسفوري للشرح المباشر وتحديد المسارات للطلاب بألوان نيون مميزة.
6. **فتح الدوائر الجاهزة (Examples):**
   - اضغط على زر **الأمثلة (Examples)** واختر أي دائرة (DOL، عكس حركة، ستار دلتا) لتتعلم كيفية توصيلها فوراً.
7. **قائمة المساعدة ودليل الرموز (Help):**
   - اضغط على زر **❓** أو اضغط على مفتاح `F1` في لوحة المفاتيح في أي وقت لفتح الدليل الشامل مع شرح أرقام أطراف الكونتاكتورات ونقاط التلامس.

## ⌨️ اختصارات لوحة المفاتيح (Keyboard Shortcuts)

| الاختصار | الوظيفة |
| :--- | :--- |
| **Shift (مع سحب السلك)** | توجيه مسار السلك بزوايا 90° قائمة هندسية |
| **الضغط فوق سلك قائم** | إنشاء نقطة تفريع جديدة فوراً (T-Junction Branch) |
| **Space + سحب بالماوس** | تحريك لوحة الرسم بسلاسة (Infinite Pan) |
| **عجلة الماوس (Scroll)** | تكبير وتصغير اللوحة (Zoom In / Out) |
| **F1** | فتح نافذة المساعدة ودليل الاستخدام الشامل |
| **R** | تدوير العنصر المحدد 90 درجة |
| **Delete / Backspace** | حذف العناصر أو الأسلاك المحددة |
| **Esc** | إلغاء التحديد وإغلاق الأدوات العائمة |
